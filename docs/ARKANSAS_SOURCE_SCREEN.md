# Arkansas source screen — September 13, 2026

Arkansas is not yet ready for a verified complete winning-ticket heat map.
The [official retailer locator](https://www.myarkansaslottery.com/retailer-locator/index)
shows names, addresses and coordinates and has pagination. An importer could
enumerate it, but completeness, active status, stable identifiers, and source
refresh behavior require validation before ranking retailers.

The [official game catalog](https://www.myarkansaslottery.com/games) and
[instant games](https://www.myarkansaslottery.com/games/instant) provide game
information. [Selected press releases](https://www.myarkansaslottery.com/press-releases)
name winning-ticket retailers, including the August 20 report of 20 claimed
$10,000 Burst top prizes over three weeks. That limited, game-specific claim
count does not represent all prize tiers or all Arkansas games. The source
does not establish complete winning-ticket counts by period or retailer.

On September 13, 2026, a data inquiry was sent to `aslinfo@arkansas.gov`,
the address displayed on the [Lottery's official contact page](https://www.myarkansaslottery.com/contact-our-team).
It requests existing draw and instant ticket/claim counts, selling retailer
links, active retailer directory, count definitions and cadence, without
personal winner information. Gmail confirmed “Message sent.” No additional
coverage is verified from sending the inquiry.
